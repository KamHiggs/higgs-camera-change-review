# camera.decision_questions — initial contract, v0.1.2

New author-tested development candidate; independent v0.1.1 execution review is historical support for that version, not approval of this new operation.

Input: `execute("camera", "decision_questions", {"camera_id": "<declared candidate>", "base": <optional ordinary camera input>})`. Omitted base uses the embedded synthetic case. No new field language or external acquisition. Only one missing `timestamp_jitter_bound_ms` is analyzed. Extra request keys and malformed ordinary inputs are input errors. A well-formed case outside the one-unknown scope gets an explicit unsupported analysis, not invented thresholds.

Output uses the common execution envelope. Completed analysis has `decision_status=conditional_evidence_analysis` and `analysis_status` supported, blocked, unsupported, or not_needed. These are analysis dispositions, not deployment or physical engineering conclusions. Include the existing execution/decision, selected plan, exact comparable cost, version and input identity; target source IDs/path/JSON locator; physical blockers and remaining unknowns; per-policy exact domains and controlling operands; piecewise conditional cost/selection effects; guarantee request; limitations; readable explanation. CLI --out writes result.json and explanation.md only.

For positive-speed variants let a_i=L_i/s_i-h_i, bias b_i, unknown nonnegative guaranteed jitter j. Intervals are [-b_i-a_i+j,-b_i+a_i-j]. Per-variant threshold is min(a_i). Shared threshold is [min(-b_i+a_i)-max(-b_i-a_i)]/2. Equality is included; negative thresholds have empty nonnegative domains. Compute with Fractions from actual input fields. Zero-speed variants impose no interval restriction after the existing required operands are known; all-zero-speed means an unbounded domain but still requires the guarantee under the inherited contract. Never divide by zero.

Preserve known failures, availability and baseline exclusion, U01, firmware and cost prerequisites. Descriptive fields absent but not required by the model are irrelevant to this operation. Multiple missing required operands lead to unsupported single-answer sufficiency. A known blocker leads to blocked without a guarantee request that falsely promises selection. If the bound is already known, report not_needed. If all timing domains are empty, return exact domains and explain why jitter alone cannot help.

For each policy expose below/at/above mathematical outcomes and exact cost points. Partition j>=0 at the analytical boundaries; each region states the cheapest feasible target policy and its consequence versus the existing established plan: create_first_feasible_plan, reduce_established_cost, add_equal_cost_alternative, more_expensive_alternative, or no_target_plan. These are conditional mathematical consequences; unresolved other candidates can still matter. Do not call a tie or a more expensive alternative a cost reduction.

Hypothetical checks at one representative per exact region reuse the existing simulation/serialization path. They do not derive the boundaries, prove every point's encoding behavior, create source facts, or grant approval. Preserve explicit hypothetical labels on inner results and selected plans, their virtual source record, exact assumed value and identity. An encoding failure remains numeric_encoding_error and withholds the plan. If the solver selects an incumbent instead, its serialization check does not validate an unselected target. No actual executable configuration is promised by the analysis; no firmware is emitted by this operation.

Request a scoped guaranteed upper jitter bound from an applicable authoritative specification (or a justified superseding record), with candidate/spec revision, variant operating conditions and provenance. Typical values, finite observations, and PASS statements are insufficient. Existing source labels are not independent authentication. Do not write authoritative inputs.

Scope excludes hardware qualification, global value-of-information optimization, probability, money, manual effort benefit, models, agents, persistent memory and general composition. The exact threshold algebra is separate from finite output encoding and the existing input magnitude limits.
